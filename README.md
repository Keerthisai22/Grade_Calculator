# Grade Calculator (Python)

A simple Python program that calculates a student's grade based on marks using conditional statements.

## Features
- Takes student marks as input
- Assigns grades automatically
- Beginner-friendly logic

## Technologies Used
- Python 3

## How to Run
1. Download or clone the repository
2. Run the program:
   python grade_calculator.py

## Sample Output
Enter the marks: 82
Grade B

## Concepts Used
- if-elif-else conditions
- Comparison operators
- User input
